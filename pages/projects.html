01 / Web development

The Seiser Systems website.

You’re looking at it. A public site built to explain the services, make contact simple, and leave room for a growing product catalog.

Type
Business website
Built with
HTML / CSS / JavaScript
Hosting
GitHub Pages

A simple structure that can grow.

The homepage brings together web development, software, and hardware services. Dedicated pages hold project notes and the product catalog, with consistent navigation throughout.

The layout adapts to small screens, with readable content, keyboard focus states, and direct links to request a quote. The review form opens an email draft so it works without a backend.

Plain HTML and CSS keep the site easy to maintain. GitHub Pages serves the static files directly, without a framework or build step.
