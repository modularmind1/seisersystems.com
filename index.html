02 / Working together

Define it. Build it. Check it.

Good work starts with understanding the job. You’ll know what we’re solving, what’s included, and what it will cost before paid work begins.

  1. 01

    Understand the problem

    Talk through the goal, constraints, and budget. I’ll explain the options and tell you if the project or repair doesn’t make sense.

  2. 02

    Agree on the scope

    Set out the work and estimate. A website, software tool, or hardware build should have a clear purpose and a manageable plan.

  3. 03

    Build and check

    Work through the details, check the result against the agreed scope, and walk through what was done and how to use it.
